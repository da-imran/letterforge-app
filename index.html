Wawasan 2020 — classic, Malaysian

Old-school paper. New-school duels.

Warm A4 vibes, blue rules, red margin. The whole game is a sheet you both write on — then argue about.

How the sheet works 📝

Owner customizes the columns before start. Everyone else just plays.

1Owner sets 3–10 columns — Food, Negara, Haiwan, anything. Bilingual presets or free text.
2A–Z shuffled — 26 rows, one letter per row, shared order for both players.
3Fill or Skip — type any valid start (“teh o ais”) or just skip it.
4Review together — both sheets revealed. Per column, mark as invalid (omit) → opponent gets 0 for that column only. Toggle back to valid if you change your mind. Then you both validate it.
5100 pts split — whole numbers only (e.g. 3 cols → 33 each). Empty/same = 0. Skipping is independent — your skip doesn’t erase opponent’s score.
6Owner can stop anytime — open/review row discarded, only done rows count.

How to play

A round in four steps.

Same loop, every mode. The rules decide when it ends.

01

Get letters

Server deals 2–4 letters. In duels, both get the same set.

02

Form a word

Valid dictionary word only. Repeats allowed. Multi-word answers work in Wawasan.

03

Get scored

10–20 pts by length. Duplicate 5. In Wawasan, independent per column.

04

Next round

New letters. Repeat until win/lose, or in Wawasan — next alphabet letter.
